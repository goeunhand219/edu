# Phase 1 — UI Design Contract

> Visual and interaction contract for "Foundation + Onboarding" — Tailwind design tokens + Screen 1 (마법사 동전 선택). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Source of truth:** `경제마법사학교_기능설명서.md` PART 2 (디자인 시스템) + PART 3 화면 1.
>
> **Audience:** 만 7~9세 아동. 한국어 단일. 모바일 프레임 375×667 우선.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (custom Tailwind theme — magical-school visual language is fully bespoke) |
| Preset | not applicable |
| Component library | none (custom React components, ~5~6 small components for Phase 1) |
| Icon library | Native emoji (🔥 💧 ⚡ 🌱 🌬️ 🪙 ✨ 🪄) per PROJECT.md decision — no icon library, no SVG sprites |
| Font | Pretendard (primary, web-loaded via CDN) → Nanum Gothic (fallback) → system-ui (final fallback) |

**Why no shadcn:** PRD specifies a custom magical-school visual language (deep purple gradient backgrounds, gold metallic coins with hover-rotation, attribute-based color system, sparkle particle background). shadcn primitives would add overhead without value for a 6-8 hour Sunday prototype with ~6 bespoke components. Manual Tailwind theme is faster and matches the design intent.

**Pretendard load (executor reference):**
```html
<link rel="stylesheet" as="style" crossorigin
  href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable.min.css" />
```
Then in Tailwind config: `fontFamily: { sans: ['Pretendard Variable', 'Pretendard', 'Nanum Gothic', 'system-ui', 'sans-serif'] }`

## Spacing Scale

Declared values (multiples of 4, child-friendly = generous):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline gaps inside coin label, sparkle micro-offsets |
| sm | 8px | Coin-to-label gap, between coin grid items (gap-2) |
| md | 16px | Default body padding, between section blocks, card inner padding |
| lg | 24px | Title-to-subtitle, subtitle-to-coin-grid, coin-grid-to-CTA |
| xl | 32px | Top-of-screen breathing room above title, bottom of screen above CTA |
| 2xl | 48px | Reserved: minimum touch target height (PLAT-02), major section breaks |
| 3xl | 64px | Reserved: future use (Phase 2 dashboard sections) |

**Border radius scale (separate from spacing):**

| Token | Value | Usage |
|-------|-------|-------|
| rounded-card | 16px | Cards, coin tile background, message popup |
| rounded-button | 24px | CTA buttons (pill shape, kid-friendly) |
| rounded-coin | 9999px (full) | Coin shape (perfect circle) |

**Exceptions:**
- Coin diameter: **80px × 80px** (per PRD 1-6) — fixed size, not on the spacing scale, sized for child finger touch with surrounding gap.
- Mobile frame: when viewed on desktop, content is constrained to `max-width: 375px` with `min-height: 667px` on a centered card with the same deep-purple gradient outside the frame.
- Touch target floor: any interactive element must satisfy `min-height: 48px` AND `min-width: 48px` regardless of declared spacing tokens (PLAT-02 absolute rule).

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 (regular) | 1.6 | 부제, 행동 가이드, 동전 라벨, 일반 텍스트 |
| Heading | 24px | 700 (bold) | 1.4 | "✨ 경제 마법사 학교 ✨" 타이틀, 화면 헤더 |
| Display | 32px | 700 (bold) | 1.3 | 큰 강조 (선택 후 메시지 "○○의 힘이 깨어났어!") |
| Label | 14px | 400 (regular) | 1.4 | 동전 하단 한글 라벨 ("불", "물" 등) — 본문보다 작게 허용 |

**Rules:**
- Maximum 4 sizes (label 14 / body 16 / heading 24 / display 32) — matches CLAUDE.md typography spec exactly.
- Maximum 2 weights (regular 400 / bold 700) — regular for body + label, bold for heading + display. Hierarchy is carried by the size scale, not weight variation (aligns with CLAUDE.md "글자 크기 큼" child-readability direction).
- Body line-height **1.6** (not 1.5) — PRD requires 줄간격 넓게 for child readability (CLAUDE.md accessibility rule).
- Letter-spacing: default (0) for body; `-0.01em` for heading/display to keep large text visually tight.
- Text alignment: center for Screen 1 (onboarding ceremony tone); left will be Phase 2/3 default.
- All Korean text must use Pretendard. No mixed-language fallback issues since UI is Korean-only.

## Copywriting Contract

**Tone (PRD PART 2-4, 5 principles — non-negotiable for all Phase 1 copy):**
1. "~해봐", "~을까?" — invitation, never command
2. 마법학교 어휘: 미션→임무, 포인트→마법 동전, 기록→마법서, 친구→마음 친구
3. Curiosity-provoking question form, not declarative
4. 7~9세 vocabulary only — no adult words
5. Positive/growth framing — discover ability, never point out lack

| Element | Copy |
|---------|------|
| App title | `✨ 경제 마법사 학교 ✨` (24px gold, centered) |
| Screen 1 question | `네 안에 어떤 마법의 힘이 깨어나고 있을까?` (16px white, centered, 2 lines) |
| Screen 1 action guide | `동전을 돌려서 느껴봐` (16px cream, centered, single line below subtitle) |
| Coin labels | `🔥 불` / `💧 물` / `⚡ 전기` / `🌱 흙` / `🌬️ 바람` (14px white below each coin) |
| Primary CTA (active) | `선택 완료 ▶` (18px bold white on magenta) |
| Primary CTA (disabled) | Same text `선택 완료 ▶` but gray surface, 60% opacity — no separate placeholder copy |
| Selection helper (no coin selected) | (none — disabled CTA itself communicates state; do NOT add error/nag text on first interaction per principle 5) |
| Post-selection message — fire | `🔥 불의 힘이 깨어났어!`<br>`용기와 결단력의 마법사` |
| Post-selection message — water | `💧 물의 힘이 깨어났어!`<br>`차분한 인내심의 마법사` |
| Post-selection message — electric | `⚡ 전기의 힘이 깨어났어!`<br>`빠른 통찰의 마법사` |
| Post-selection message — earth | `🌱 흙의 힘이 깨어났어!`<br>`단단한 꾸준함의 마법사` |
| Post-selection message — wind | `🌬️ 바람의 힘이 깨어났어!`<br>`따뜻한 나눔의 마법사` |
| Empty state | not applicable (no list/data on Screen 1) |
| Error state | not applicable (Screen 1 has no failable network/storage paths) |
| Destructive confirmation | not applicable (no destructive actions in Phase 1) |

**Forbidden phrases (would violate tone principles):**
- ❌ "선택해주세요" → ✅ "동전을 돌려서 느껴봐"
- ❌ "필수 항목입니다" → ✅ (silent disabled state)
- ❌ "포인트 획득" → ✅ "마법 동전"
- ❌ "기록하기" → ✅ "마법서에 적기"

## Interaction Specifications (Screen 1)

> Phase-specific contract beyond standard sections. Executor and checker reference these directly.

### Background sparkle particles (DSGN-02)
- 20~30 small white-to-gold dots, 2~4px diameter
- Float upward from bottom edge, opacity 0 → 1 → 0 over 8~12s
- CSS-only (`@keyframes` translateY + opacity). No JS animation library.
- `pointer-events: none`, `aria-hidden="true"`
- `prefers-reduced-motion: reduce` → freeze particles at random positions, no animation

### Coin idle state
- 80×80px circle, gold metallic gradient, 3D drop shadow
- Idle "breathing" float: translateY ±2px, 2s ease-in-out infinite alternate
- Center: attribute emoji at 40px font-size
- Bottom (16px below coin): label text 14px white centered

### Coin hover state (desktop only)
- `transform: rotateY(360deg)` over 1.5s linear infinite
- Adds gold glow: `filter: drop-shadow(0 0 12px rgba(251, 191, 36, 0.6))`
- Cursor: pointer
- On touch devices: hover-rotate is skipped; tap goes directly to selected state

### Coin selected state (ONBO-02)
- Stops rotation, snaps to face-front (rotateY 0)
- Adds 3px solid gold ring (`box-shadow: 0 0 0 3px #FBBF24, 0 0 24px rgba(251,191,36,0.6)`)
- Scales to 1.1× (`transform: scale(1.1)`, transition 300ms ease-out)
- All other 4 coins fade to `opacity: 0.4` (transition 300ms)
- Selecting a different coin instantly transfers selected state (single-select radio behavior)

### CTA button states
- Disabled (no selection): `bg-white/20 text-white/40 cursor-not-allowed` — no hover effect
- Active (selection made): magenta gradient + 8px gold glow on hover, `transform: translateY(-1px)` on hover
- Pressed: `transform: scale(0.98)` for 100ms tactile feedback
- Min height 48px (PLAT-02), horizontal padding 32px, full-width on mobile with 16px side margins

### Post-selection transition (ONBO-03)
- On CTA click: full-screen overlay fade-in (300ms) over the dimmed background
- Centered message card: 32px display text + 16px subtitle, surrounded by attribute-color glow halo
- Hold for 1000ms (1 second per ONBO-03)
- Fade-out (300ms) → route to `/dashboard` (Phase 2 placeholder route)
- During this entire 1.6s window, all other interaction is blocked (cannot click anywhere else)

### Accessibility (children + assistive tech)
- All coins have `role="radio"` inside a `role="radiogroup"` with `aria-label="마법 속성 선택"`
- Selected coin has `aria-checked="true"`
- Each coin has `aria-label="불 마법"` etc. (full Korean label, not just emoji)
- CTA disabled state uses `aria-disabled="true"` (not `disabled` attr — keeps it focusable so child can hear "비활성화됨")
- Focus visible ring: `outline: 3px solid #22D3EE` (cyan) `outline-offset: 4px` — distinct from selected gold ring
- All interactive elements reachable by Tab in document order: coin1 → coin2 → coin3 → coin4 → coin5 → CTA
- `prefers-reduced-motion`: replace rotation with static gold-glow pulse; replace 1.1× scale with ring-only highlight; transition message instant (no fade)
