# Requirements: 경제 마법사 학교

**Defined:** 2026-05-10
**Core Value:** 아이가 소비를 기록할 때 그 순간이 "마법 의식"처럼 느껴져야 한다. 화면 1→2→3의 흐름이 마법학교의 톤으로 작동해야 한다.

## v1 Requirements

화면 1~3 + 디자인 시스템 + 플랫폼 기반. 일요일 하루 안에 완성 목표.

### Onboarding (화면 1)

- [ ] **ONBO-01**: 사용자가 5속성 마법(불·물·전기·흙·바람) 중 하나를 동전 클릭으로 선택할 수 있다
- [ ] **ONBO-02**: 동전이 호버 시 회전, 클릭 시 선택 상태(골드 테두리·1.1배 확대·타 동전 흐림)로 표시된다
- [ ] **ONBO-03**: "선택 완료" 클릭 시 속성별 메시지 1초 표시 후 메인 화면으로 전환되고 selectedMagic이 저장된다

### Dashboard (화면 2)

- [ ] **DASH-01**: 메인 화면에 인사말·캐릭터 카드(속성·레벨·마법 동전 수)가 표시된다
- [ ] **DASH-02**: 캐릭터 일러스트(이모지+CSS 효과)가 위아래 떠다니는 애니메이션(3초 주기)으로 보인다
- [ ] **DASH-03**: 오늘의 수업 카드·이번 주 임무 카드(진행률 바 포함)가 표시된다
- [ ] **DASH-04**: "오늘의 소비 기록하기" 큰 마젠타 버튼이 표시되고 클릭 시 화면 3으로 진입한다
- [ ] **DASH-05**: "부모님 화면 보기" 작은 보조 링크가 표시된다 (v1에선 placeholder)

### Recording (화면 3)

- [ ] **REC-01**: 사용자가 구매 품목을 텍스트로, 금액을 숫자로 입력할 수 있다 (금액 자동 콤마 포맷)
- [ ] **REC-02**: 사용자가 5종 감정 스티커(꼭 필요/잠깐 고민/그냥 갖고싶어/후회돼/최고야) 중 하나를 선택할 수 있고, 선택 시 시각적으로 강조된다
- [ ] **REC-03**: 모든 항목 입력 시에만 "마법서에 적기" 버튼이 활성화되고, 미입력 시 어떤 항목이 비었는지 안내한다
- [ ] **REC-04**: "마법서에 적기" 클릭 시 record(item·amount·emotion·timestamp)가 localStorage에 저장되고 메인 화면으로 복귀한다
- [ ] **REC-05**: "← 돌아가기" 버튼으로 입력 취소 후 메인 화면으로 복귀할 수 있다

### Design System

- [ ] **DSGN-01**: 디자인 토큰(딥 퍼플 톤·골드/시안/마젠타 액센트·5속성 컬러)이 Tailwind config에 정의되어 모든 화면에서 일관 사용된다
- [ ] **DSGN-02**: 한글 폰트(Pretendard)·폰트 사이즈 체계(16/24/32px)·별가루 입자 배경이 적용된다
- [ ] **DSGN-03**: 마법학교 카피 톤(초대형 어휘·"~해봐"·마법학교 용어 일관)이 모든 텍스트에 적용된다

### Platform

- [ ] **PLAT-01**: 모바일 비율(375×667) 우선, 데스크톱에서도 모바일 프레임 안에서 보인다
- [ ] **PLAT-02**: 모든 인터랙션 버튼이 최소 높이 48px 이상이다 (아이 손가락 터치)
- [ ] **PLAT-03**: localStorage로 user·records가 영속화되어 새로고침 후에도 유지된다
- [ ] **PLAT-04**: Vercel 또는 Netlify에 배포되어 시연용 공개 URL이 확보된다

## v2 Requirements (Stretch — 시간되면)

화면 4~6. 일요일에 1~3 완성하고 여유 시간 생기면 진행. PRD 문서 PART 4 참조.

### Friends (화면 4)

- **FRND-01**: 화면 3 저장 후 감정에 따라 다른 몬스터(충동이/낭비괴/비교마/미루미/후회씨)가 등장한다
- **FRND-02**: 몬스터 → 마음 친구(결단이/계획이/자존이/꾸준이/배움이) 변신 애니메이션이 재생된다
- **FRND-03**: 만난 친구가 도감(friends 배열)에 추가되고 localStorage에 저장된다

### Lesson (화면 5)

- **LESN-01**: 오늘의 마법 수업 1개가 카드 형태로 표시된다 (제목·간단한 본문)
- **LESN-02**: 수업 완료 시 마법 동전 +N 보상이 user.coins에 누적된다

### Parent (화면 6)

- **PRNT-01**: 주간 리포트(기록 횟수·만난 친구 수·완료 수업·임무 진행률)가 표시된다
- **PRNT-02**: 대화 가이드 카드 1개가 표시된다 (부모 ↔ 아이 대화 주제 제안)

## Out of Scope

| Feature | Reason |
|---------|--------|
| 실제 백엔드 / DB | 프로토타입이라 localStorage로 충분, Sunday 일정에 부담 |
| 부모-아이 계정 분리·실제 가족 연동 | 화면 6은 placeholder만, 실제 멀티유저는 v2+ |
| 28주 마법사 커리큘럼 풀 콘텐츠 | 화면 5는 1~2개 샘플만, 나머지 placeholder |
| AI 생성 캐릭터 일러스트 | 일요일 일정 부담, 이모지+CSS로 대체 (추후 PNG 교체 가능 구조) |
| 모바일 네이티브 앱·React Native | 웹만, 포트폴리오·시연용으로 충분 |
| 실제 결제·용돈 송금·금융 API | 교육 시뮬레이션 목적이지 진짜 금융 처리 아님 |
| 다국어 지원 (영어 등) | 한국어 단일, 타겟이 국내 7~9세 |
| 회원가입·로그인·인증 | localStorage 사용 = 단일 디바이스 단일 사용자 가정 |
| 자동화 테스트 (Jest/Playwright) | 시연용 프로토타입에 과함, 수동 확인으로 대체 |
